OG image generator

Open this file in a browser and click Download all. Put the five PNGs in irforge/public/og/ keeping their filenames. The build picks them up automatically — each language's page then points og:image at its own card, and any language whose file is missing falls back to /og-image.png, so a partial set is safe to ship. Replace these with proper artwork whenever a designer has time; only the filenames matter.
