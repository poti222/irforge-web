# NOT disallowed on purpose: /dashboard, /login, /register, /forgot-password,
# /reset-password. A page robots.txt blocks can't show a crawler its `noindex`,
# and Google may keep a blocked-but-linked URL in the index as a bare result.
# For these the server answers with `X-Robots-Tag: noindex, follow` (and the app
# shell carries the same <meta name="robots">), so a crawler may fetch them and
# will drop them. See CRAWLABLE_NOINDEX_ROUTES in src/lib/lang-routing.ts —
# scripts/ssg.mjs fails the build if one of them gets a Disallow here.
#
