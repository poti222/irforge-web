# Per-language OG images

Drop `og-fa.png`, `og-en.png`, `og-ar.png`, `og-tr.png`, `og-ru.png` here
(1200×630).

Generate a starter set by opening `irforge/scripts/og-generator.html` in a
browser and clicking **Download all**, or replace them with proper artwork —
only the filenames matter.

The build wires each language's page to its own card and falls back to
`/og-image.png` for any language whose file is missing, so a partial set is
safe to ship.
